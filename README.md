# Portfolio Website

A personal portfolio website for Barnabas Shrestha, a Computer Engineering student at Kathmandu University.

## Overview

The website highlights Barnabas's:

- About and background
- Selected projects
- Technical skills and areas of interest
- Workshops and community experience
- Contact information and résumé

## Technologies

- HTML
- CSS
- JavaScript

## Project Structure

```text
.
├── assets/    # Images, logos, and résumé
├── index.html # Main website page
├── script.js  # Navigation, theme, and interaction logic
└── styles.css # Website styles
```

## Run Locally

From the repository root, start a local HTTP server:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
